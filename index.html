About the project

Built around a useful question.

Where can a young person find practical training that fits their location, time, and budget? Skills Finder explores that question through a community resource directory for school leavers aged 18–25 in Uganda.

This student project is being developed during the Ishvexa Hub Web Development internship. The current version is the first HTML page; dedicated centre details and About pages will follow.

All listing content is invented for this demonstration. Place names provide sample location context. The visual identity uses text and CSS, with system fonts and no external images.
